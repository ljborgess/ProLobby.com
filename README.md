# ProLobby

Plataforma de matchmaking/comunidade pra EA FC Pro Clubs: cadastro de personagem verificado por print+OCR, fila automatizada por posição, formação de times equilibrados, coordenação via Discord, report de resultado e ranking (elo + reputação).
